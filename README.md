# Curse of Vakapora
A mysterious man/monster has gotten into your house. You must search the house to find keys inorder to unlock the front door and escape. <br>
This is a short horror/puzzle game I made on roblox studio. It features multiple endings, a monster that tracks and follows players, and tools that can help you escape.


# How to play
Go to the roblox page: https://www.roblox.com/games/114207264370977/Curse-of-Vakapora?page=userProfilePage&placeId=114207264370977&position=1&universeId=10772856305 <br>
